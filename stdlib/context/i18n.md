## Internationalization

Locale detection, translations, and number/date/currency formatting.

```lua
-- Lua
local i18n = require("hull.i18n")

i18n.load("en", { messages = { greeting = "Hello, ${name}!" }, decimal = ".", thousands = "," })
i18n.load("de", { messages = { greeting = "Hallo, ${name}!" }, decimal = ",", thousands = "." })

i18n.locale("en")
i18n.t("greeting", { name = "Alice" })   -- "Hello, Alice!"
i18n.number(1234.5)                       -- "1,234.5"
```

```javascript
// JS
import { i18n } from "hull:i18n";

i18n.load("en", { messages: { greeting: "Hello, ${name}!" }, decimal: ".", thousands: "," });
i18n.load("de", { messages: { greeting: "Hallo, ${name}!" }, decimal: ",", thousands: "." });

i18n.locale("en");
i18n.t("greeting", { name: "Alice" });   // "Hello, Alice!"
i18n.number(1234.5);                     // "1,234.5"
```

## API

- **`i18n.load(name, table)`** - register a locale with translations and format rules
- **`i18n.locale(name?)`** - get or set active locale
- **`i18n.t(key, params?)`** - translate key with `${variable}` interpolation. Supports dot-path keys.
- **`i18n.number(n)`** - format number with locale-specific decimal/thousands separators
- **`i18n.date(timestamp)`** - format date string
- **`i18n.currency(amount, code)`** - format currency with symbol and locale rules
- **`i18n.detect(accept_language_header)`** / `i18n.detect(...)` - detect best locale from `Accept-Language` header

## Locale Definition

```lua
i18n.load("en", {
    messages = {
        greeting = "Hello, ${name}!",
        nav = {
            home = "Home",
            about = "About",
        },
        items = "${count} item(s)",
    },
    decimal = ".",
    thousands = ",",
    currency = { USD = { symbol = "$", position = "before" } },
    date_format = "%Y-%m-%d",
})
```

Dot-path keys: `i18n.t("nav.home")` returns `"Home"`.

## Per-Request Locale

```lua
app.use("*", "/*", function(req, res)
    local lang = i18n.detect(req.headers["accept-language"])
    if lang then i18n.locale(lang) end
    return 0
end)
```

## Complete Example

```lua
local i18n = require("hull.i18n")
local template = require("hull.template")

i18n.load("en", {
    messages = {
        welcome = "Welcome, ${name}!",
        cart = {
            total = "Total: ${amount}",
            items = "${count} item(s) in your cart",
        },
    },
    decimal = ".",
    thousands = ",",
    currency = {
        USD = { symbol = "$", position = "before" },
    },
    date_format = "%m/%d/%Y",
})

i18n.load("de", {
    messages = {
        welcome = "Willkommen, ${name}!",
        cart = {
            total = "Gesamt: ${amount}",
            items = "${count} Artikel in Ihrem Warenkorb",
        },
    },
    decimal = ",",
    thousands = ".",
    currency = {
        EUR = { symbol = "\226\130\172", position = "after" },
    },
    date_format = "%d.%m.%Y",
})

-- Detect locale per request
app.use("*", "/*", function(req, res)
    local lang = req.query.lang or i18n.detect(req.headers["accept-language"]) or "en"
    i18n.locale(lang)
    return 0
end)

app.get("/", function(req, res)
    local html = template.render("home.html", {
        welcome = i18n.t("welcome", { name = "Alice" }),
        total = i18n.t("cart.total", { amount = i18n.currency(29.99, "USD") }),
        formatted_date = i18n.date(os.time()),
        big_number = i18n.number(1234567.89),
    })
    res.html(html)
end)
```

```javascript
import { i18n } from "hull:i18n";

i18n.load("en", {
    messages: { welcome: "Welcome, ${name}!" },
    decimal: ".", thousands: ",",
    currency: { USD: { symbol: "$", position: "before" } },
});

app.use("*", "/*", (req, res) => {
    const lang = req.query.lang || i18n.detect(req.headers["accept-language"]) || "en";
    i18n.locale(lang);
    return 0;
});

app.get("/", (req, res) => {
    res.json({
        welcome: i18n.t("welcome", { name: "Alice" }),
        price: i18n.currency(29.99, "USD"),
        count: i18n.number(1234567),
    });
});
```

## Notes

- `i18n.detect()` parses the `Accept-Language` header and returns the best matching loaded locale, or `nil`.
- Missing translation keys return the key itself (e.g., `"nav.missing"` returns `"nav.missing"`).
- Locale state is global. In concurrent requests, set locale in middleware before each request.
